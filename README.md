# MekNH Ores

> ## ⚠️ 重要说明
>
> **本模组专为 Mekanism：New Horizon 整合包设计，不保证独立安装与其他整合包的兼容性。**
>
> - 清理列表、矿脉接管与 JEI 隐藏都依赖该整合包的 KubeJS 脚本；单独安装时这些脚本不存在，行为会与预期不同。
> - 矿脉接管会替换目标矿石的原生成；与其它修改世界生成的模组同时使用时可能互相覆盖。
> - 只有在该整合包环境中才会进行测试与问题修复；其它环境的崩溃、配方冲突、世界生成异常不在支持范围内。
> - 如需在自己的整合包中使用，请自行验证并承担相应风险。

MekNH Ores 是Mekanism：New Horizon整合包的**统一矿辞 + 矿物生成清理**模组。
